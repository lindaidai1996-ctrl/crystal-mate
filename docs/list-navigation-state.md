# 列表导航与查询条件

查询条件属于当前这一轮浏览，菜单入口代表重新开始。

- 从列表打开详情、编辑、采购明细或批次，再用页面返回、保存后返回或浏览器后退回到列表时，继续使用原有列表状态，包括搜索、筛选、排序、页码和每页条数。
- 使用桌面菜单、移动端菜单或账号入口切换页面时，统一清除上一轮浏览中所有列表的查询状态。之后再从菜单进入任何列表，都使用默认条件；再次点击当前列表菜单也会重置。
- 表格／图片模式和图片密度属于展示偏好，菜单切换时保留。编辑草稿、隐私模式等其他存储不参与列表重置。
- 页面内的详情链接、返回按钮和语言切换不触发菜单重置。菜单离开被未保存内容确认框取消时，查询条件仍保留。

`useSessionListState` 复用 `session-list-state.ts` 保存列表状态；仅菜单导航在离开保护通过后调用 `resetListVisit`，并更新页面子树的 key，覆盖使用本地状态的表格及再次点击当前菜单的情况。显式链接携带的查询参数仍遵循目标页面现有规则。

验证：存储层单元测试覆盖返回读取、多个列表及详情状态清除、展示偏好和草稿隔离、状态订阅、存储不可用时的内存回退。类型、格式及局部 lint 检查用于验证接入；未验证真实账号的浏览器完整流程。
