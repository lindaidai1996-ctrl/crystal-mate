# 物料统一计价

入口：`/admin/material-pricing`。按克管理的物料可以关联到一个计价组，组内采购仍保留原物料、渠道商、批次、金额、重量与库存。提供 S925亮银、清迈银、精工银三个名称预设，由用户关联真实物料，不按名称自动归类或合并。

## 页面结构（2026-11-20）

统一计价采用概览与子页面：

- `/admin/material-pricing`：定价概览，展示主要成本指标与价格发布操作；详细成本、行情和计算说明默认收起。
- `/admin/material-pricing/purchases`：采购明细，独立使用完整内容宽度，支持全部计价组或指定组、供应商、采购日期和汇总方式筛选。
- `/admin/material-pricing/analytics`：采购分析，按时间、计价组和渠道商查看采购趋势、占比与价格。
- `/admin/material-pricing/distributors`：渠道商对比，按当前计价组独立展示采购重量、金额与平均成本。
- `/admin/material-pricing/history`：调价历史，独立分页查看发布记录及其定价依据。

各页使用同一顶部导航，通过 `group` 查询参数保留选中计价组，支持直接打开、刷新和浏览器返回。计价组选择改为紧凑的顶部选择器，表格不再受左侧组列表挤压。采购日期筛选复用公共 `DateRangeFilter`（含手机日期抽屉），采购录入及导入核对复用公共 `DateInput`。

本次页面拆分的 **AI 助手影响：无需同步**。只调整页面布局、导航和日期组件，继续使用原有接口、采购/成本口径及价格隐私逻辑；不新增助手查询能力。

页面拆分验证：全仓类型、定向 lint 和全仓格式检查通过；使用已有开发数据只读检查四个页面在1440、768、390、320px的显示，无页面横向溢出，未捕获控制台错误或警告。已验证计价组切换、跨页导航、刷新、浏览器返回、英文对比页及公共日期输入/手机日期抽屉。未提交采购、导入或价格发布；本次不验证业务保存、生产构建及部署。截图与检查结果位于忽略目录 `.cache/material-pricing-pages/`。

## 采购分析与渠道商筛选（2026-11-20）

采购明细和采购分析的渠道商筛选只列出当前计价组、采购日期范围中实际出现的渠道商，基于完整筛选结果而非当前表格页。选中渠道商不缩窄自身候选列表；切换条件后，已不在范围中的选项不再生效。新增/编辑采购仍使用完整渠道商字典，允许向尚无采购的渠道录入新采购。

采购分析独立位于 `/admin/material-pricing/analytics`，复用台账读取接口及公共 `DateRangeFilter`。按日、月、年查看采购重量、银料实付、加权实际克价和加权折前报价；趋势横轴按自然时间间隔排布，只绘制有记录的周期，不把未记录周期推断为零采购。趋势图支持鼠标、触摸和方向键查看。

渠道商及计价组环形饼图可切换重量/实付占比，点击图例可查看各项数值；以已知正值计算占比，超过七项合并为“其他”，零值和缺失不绘制扇区。渠道商价格图可切换加权实际价、加权折前报价、最近采购实际价和最近采购折前报价，从低到高排列。全部计价组可分析重量/实付构成；价格趋势和排名须限定单个组，明细始终按渠道商与计价组分别统计，避免不同银料混算克价。

统计采用筛选下的完整台账，继续遵循接口5000条上限，超限报错，不使用截断数据。包含未来采购及未纳入定价成本的采购；不用于估算当前库存成本或货损。金额和重量各自汇总已知值，缺失数单列，真实零实付有效。加权实际克价只使用重量为正且实付已知的同一组样本；加权折前报价只使用明确 `BEFORE_DISCOUNT` 且报价已知、重量为正的样本，旧 `LEGACY` 报价不参与。综合折扣只使用重量为正、实付已知且折前报价大于零的匹配样本。使用独立40位精度的 Decimal 运算，价格最后取四位小数，不平均已舍入的行克价。

最近采购价格取筛选范围内最近一条明细，缺失不回填旧价；同日多条按ID稳定排序，不代表日内先后。表格分别给出实际价/报价样本数。价格脱敏时，实付、克价、折前报价、折扣及相关图表、图例、悬浮提示和金额指标会立即移除，重量和条数仍可查看。

**AI 助手影响：无需同步现有查询能力。** 新增客户端只读分析与筛选交互，不改变原采购、库存、定价成本或权限；图表及派生的报价/折扣分析未接入助手工具或模型证据，不能据此声称助手已支持相应自然语言分析。现有采购与库存查询继续读取原业务事实。

本次分析验证：29项相关单元检查通过，覆盖加权精度、真实零值、缺失与旧报价、跨年时间分组、不同计价组隔离、501条完整汇总及组/日期范围内的渠道商候选。通过实际开发数据只读浏览核对全量汇总及筛选候选，1440/768/390/320px无页面横向溢出；多渠道商模拟响应覆盖图表/筛选联动、日期筛选、报价对比、图例交互、多组价格保护、空数据、中英文和即时脱敏，未捕获浏览器错误或警告。类型、定向lint及全仓格式检查通过。未新增或运行完整E2E套件，未提交采购/价格或修改数据库，未运行生产构建、部署或真实AI调用。截图与结果位于忽略目录 `.cache/pricing-analytics/`。

## 配置与成本

采购录入、折前报价与历史Excel导入见[银料采购台账](silver-procurement.md)。台账复用真实采购，折前报价不进入成本；历史采购重量参与计价，剩余库存记为未知。

每组只有一个货损率，默认0%，允许0%～99.99%，保留两位小数。物料/批次原有货损字段继续服务普通批次定价，统一计价不叠加这些字段。不提供实际报损、损坏、回收功能，也不修改库存或真实采购金额。

历史采购平均成本＝全部有效采购总金额÷采购总重量；含货损估算成本＝平均成本÷（1－组货损率）。各批次先汇总再相除，中间不按分提前舍入，成本克价最后四舍五入到分。明确零金额采购有效；缺金额、非正重量、未来采购日分别列为未纳入，界面显示具体原因。历史成本是采购平均估算，不是准确的当前库存成本。

采购服务在 RepeatableRead 事务内按游标每次读取500行直至完整，不以页面结果或单页作为全量。页面展示全部历史、近90个北京时间自然日（含今天）、最近采购及按渠道商的成本对比。修改组货损率仅更新新参考，既有发布和 DIY 不变。

## 行情和发布

复用既有 Ag(T+D) 行情服务，价格为元/克，保留源更新时间。联动系数初始1，仅为用户可调整的参数，不根据材质名称推断纯度。历史行情请求覆盖90天样本及额外30天休市回溯；采购日无交易时使用不晚于采购日的最近交易日参考收盘价。当日行情点可能尚未收盘。

补货参考价＝近90天采购均价＋联动系数×（最新银价－按采购重量加权的采购日行情均值）；再除以（1－组货损率）。近期样本没有对应行情时不使用不完整样本代替全体，显示行情不可用。

定价依据取历史与补货两种含货损成本的较高值。比例加价、每克固定加价、自定义售价、目标毛利率分别计算；毛利率必须小于100%，建议价向上取到分。行情失败、无近期样本、负数或超范围补货参考价明确提示，继续使用历史成本。没有有效历史成本时不能发布或启用。

读取或刷新页面时重算建议，不增加定时任务。发布售价可以手动修改或低于建议；发布事务校验组版本、采购/配置指纹并重新计算依据，保存生效时间、实际售价、货损率、规则、行情与汇总依据。同日可多次发布，历史记录不更新。指纹包含北京时间日期，因此跨日会提示复核。

首次使用“发布并启用”，在同一事务中保存售价和启用计价组，任一步失败均回滚。首次发布仍要求有效采购成本，并校验版本与采购/配置指纹；发布成功后即可在 DIY 中选择，无需返回组配置启用。已有发布记录时，按钮为“确认发布价格”，仅更新售价，保留当前启用/停用状态；停用组再次调价不会自动启用，可在组配置中单独启用或停用。

启用组关联物料从普通 DIY 批次选择、快搜、图片匹配和候选搜索中排除，历史普通用料可继续编辑。停用组恢复普通入口，旧统一计价行仍然可读取和修改；新行不能选择停用组。关联物料在解除关联前不能更正为非克单位。

首次发布并启用的 **AI 助手影响：无需同步**。已复核助手能力目录，组配置、发布和调价历史仍未接入助手；本次仅合并原有业务操作，不改变采购金额、成本计算、库存、权限或助手查询口径。

首次发布并启用验证：17项相关单元检查通过，覆盖自动启用、后续调价保留启停状态、无有效成本、版本过期和模拟写入失败回滚，以及既有计算与认证边界。全仓类型、定向 lint 和全仓格式检查通过。真实数据库集成用例已同步首次发布与停用后调价的预期，但因未配置专用测试库而跳过；本次未验证真实数据库事务及实页操作，未运行生产构建或部署。

## DIY 与兼容

统一计价用料支持多行。克重代表每件成品实际用量，成本克价已分摊货损，计算行总额时不再次增加货损或用量。选料带出当前含货损成本与已发布售价，可分别手改；只有新增或主动“更新价格”读取新值。

服务端签名成本依据绑定计价组、发布版本、名称、原始成本、货损率与含货损成本，防止客户端改写来源。实际采用成本/售价允许手动覆盖，并与原参考分开保存。编辑已有行保留原依据，凭现有行身份可编辑停用组，也可在认证密钥轮换后保留原快照；新选择必须使用有效签名和启用组。旧 API 省略新用料集合时，服务端保留已有集合与成本，不静默删除。

`ProductDiyRun.legacySilver` 对历史记录默认为true；新建仅使用组计价时写false，隐藏旧通用银料编辑器。保留旧银料字段及 `/api/settings/silver-pricing`，旧商品与旧图片草稿不推断所属银饰类型。图片导入新增统一计价集合，新草稿不初始化旧银料计价，旧草稿缺少标记时保留原行为。

报价、成本总计、商品名片和用料数量摘要覆盖新用料行。对客输出显式列举名称、克重、售价及小计，不输出成本、货损、采购、令牌和内部版本。已保存商品与已生成名片不随调价更新。后台成本、建议价及定价参数跟随现有价格隐私模式隐藏。

## 接口与迁移

- `/api/material-pricing-groups`：GET组与可关联物料；POST创建组。
- `/api/material-pricing-groups/{id}`：PATCH完整配置，提交当前version。
- `/{id}/preview`：GET成本、采购明细、行情、建议与指纹。
- `/{id}/publish`：POST提交version、fingerprint、saleGramPrice。
- `/{id}/history`：GET分页发布历史；`/options`：GET启用组当前选料参考。

接口均沿用认证、管理员写入及同源校验，响应no-store。写入接审计；计价组、发布、DIY行都纳入审计，子记录关联到计价组或商品。并发或过期发布返回409，UI提示刷新。

迁移：`20261120000000_material_pricing_groups`。只增加三张表、物料关联列及旧银料兼容标记，不创建业务记录，不修改采购或库存。先在隔离测试库验证，再单独应用开发库本次SQL并标记迁移，生产不在本次范围。
