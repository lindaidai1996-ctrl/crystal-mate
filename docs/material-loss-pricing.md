# 物料货损补偿定价

物料编辑保留成本价、比例加价、固定金额加价、自定义金额规则，并区分以下三个价格：

1. **基础售价**：按原始进货成本和规则生成，也可直接修改。修改任一基础价格会将基础定价切换为自定义金额，保留其他基础价格。
2. **含货损建议售价**：基础售价 ÷（1 − 预计货损率），使用整数金额计算，向上保留两位小数。
3. **最终销售价（实际售价）**：编辑器按定价规则与基础价自动带出。未填货损率或填写 0% 时等于基础价；填写正货损率时等于含货损计算结果。保存后仍写入现有实际售价字段，用于库存展示和 DIY 报价，无需再次采纳。

例如：成本 100 元，按 30% 加价得到基础售价 130 元；预计货损 10%，建议售价为 144.45 元。重复计算始终以基础售价计算，不在已补偿售价上重复增加货损。

## 交互与范围

- 支持串、颗、克的现有价格字段。比例基础定价沿用原有向上取整到元的规则；货损补偿单独向上取整到分。
- 基础售价和货损配置作为内部定价信息，在价格隐私模式下隐藏；实际售价仍可编辑。审计详情中的货损率与基础价格也按隐私模式隐藏。
- 货损率允许 0% 至 99.99%，两位小数。未配置或填写 0% 时不展示重复的货损建议价，保留 `null` 与明确填写 `0` 的区别。
- **定价为主、货损为辅**：加价规则与基础价始终在售价区上方直接展示，不折叠为辅助功能。货损率保留在基础价下方的小型可选字段，说明放入提示。最终销售价紧随其后，串、颗、克均自动带出，可直接手动调整。
- 选择／修改加价规则或参数会重新自动带出全部最终售价；手动修改基础价时切换为自定义定价，并自动填入对应的最终售价。修改、清空或填写 0% 货损率也会重新计算全部最终售价，不需要“采纳”。
- 直接手动调整最终售价后，后续成本、重量、颗数等变化保留该项手动价；再次调整对应基础价、选择加价规则或修改货损率则按新定价重新带出。清空最终售价恢复自动计算。普通编辑器与图片导入完整编辑器复用相同逻辑，图片识别明确给出的售价仍作为手动实际价保留。
- 缺少基础售价不生成建议；超出金额上限时不允许采纳。实际售价可以低于建议价，页面提示但不阻止保存。
- 整串按单颗售价换算、单价换算克价的原有建议使用**实际售价**，不会再补偿一次货损。
- 基础整串／单颗售价下显示**基础克价 × 对应重量**的建议，点击“采纳基础价”填入该基础售价、切换为自定义金额，并自动更新对应最终销售价。修改克价、重量或颗数仅更新换算建议，不自动改写其他基础售价；未手动覆盖的最终售价继续跟随各自定价结果。
- 串物料优先使用填写的单颗克重计算单颗建议；未填写时，用基础克价 × 整串重量 ÷ 颗数估算，并标注估算来源，中间不先舍入均重。克计量物料不显示此换算建议。
- 基础克价换算使用整数运算，最终四舍五入到分；不额外按比例规则向上取整或叠加货损。缺少有效依据、正数结果舍入后不足 0.01 或超出金额上限时不能采纳；明确的零售价允许换算。建议遵循基础定价的隐私及禁用状态。
- 毛利预览以实际售价减去含预计货损的单位成本，明确标注未计其他费用。它是定价估算，不是财务利润。
- 新建物料的货损率同时保存为物料默认值和首个批次值。编辑物料基本资料只修改默认值，已有批次保留自己的配置。
- 新增批次预填物料默认值，可以单独修改。API 未提供货损率时复制物料默认值；明确提供 `null` 时保留未配置。
- 图片导入的完整物料编辑器复用相同交互。选择已有物料时带入该物料默认货损率；识别得到的售价仍保留为实际售价。
- 批量改价仍是用户显式要求重设实际售价的独立操作，沿用原有规则，不自动附加货损。

## 数据及兼容

`Material` 与 `MaterialBatchEntry` 新增 `lossRate`、`baseSaleUnitPrice`、`baseSaleGramPrice`、`baseSaleChildUnitPrice`。既有 `saleUnitPrice`、`saleGramPrice`、`saleChildUnitPrice` 继续代表实际售价，因此列表、DIY 报价和已保存报价快照无需改变读取口径。

迁移：`prisma/migrations/20261118000000_material_loss_pricing/migration.sql`。迁移复制原有售价作为基础价格的初始值，不修改实际售价、采购金额或库存。规则定价的基础价格在编辑时按原规则计算；原有实际售价保持原值。

旧草稿和未提供基础价格字段的旧 API 请求保留兼容计算。新编辑器显式初始化完整基础价格字段；接口要求新增的三个基础价格字段同时提供或同时省略。

开发环境已只读确认该迁移记录及新增字段存在；生产环境未操作。部署应用前必须先应用迁移并重新生成 Prisma Client，正在运行的服务应重新启动以加载新客户端。

## AI 助手影响

**AI 助手影响：无需同步现有查询能力。** 定价结果在编辑器自动填入原有实际售价字段，保存后助手仍读取已保存的业务事实，不临时推算售价。不改变实际采购金额、采购数量和库存口径。已检查助手 `candidate-data.ts`、`display-data.ts`、`purchase-data.ts` 的显式字段选择；新货损字段和基础售价不进入候选证据、采购汇总或模型输入。

本轮不新增助手查询货损率、建议售价或估算毛利的能力，也不将预计损耗描述为实际库存损失。如未来要支持这些问题，需要独立扩充受控查询契约、价格隐私与金额计算，不能假定页面新增字段后助手自动支持。
