# P7—P10 场景验收矩阵

2026-11-18。冻结基线不改写；构造数据用于验证同名、未知、单位/币种等边界，不写入业务库。独立运行 `check-ai-assistant-agent.ts`，真实模型需要 `--real`，开发库需要隔离启动器及 `--dev`。

| 场景          | 代表输入                               | 验收结果                                                       |
| ------------- | -------------------------------------- | -------------------------------------------------------------- |
| 仅名称        | 本月荔湾进了哪些货，仅名称             | 去重名称链接，无附加表格/金额/库存；与独立 reader 身份数量一致 |
| 指定字段/表达 | 只给名称、采购单价、单位，表格显示     | 仅指定字段，缺失为未知，单价不偷换为金额                       |
| 模糊找货      | 小号银色方形配件叫什么                 | 按字段证据找候选，歧义不擅选                                   |
| 多条件/排除   | 本月银配件，不要耳钩定位管，只看有库存 | 保留日期语义，排除与库存筛选作用于后端集合                     |
| 连续追问/纠正 | 改为上个月，其他要求不变               | 仅替换日期、保留名称表达；旧答案可见且标记观察时间             |
| 重置          | 重新查一个问题                         | 清除旧范围、表达和整理要求                                     |
| 库存口径      | 这些剩多少/这次买的剩多少              | 原 R08 两种口径保持；未知余量非零                              |
| 去重/身份     | 同名异物、多批次、多规格               | 不按名字合并；单批次/多批次链接正确                            |
| 汇总/排名     | 按渠道商统计金额，最多在前             | 后端分组排序，真实渠道商身份，未知计数保留                     |
| 期间比较      | 本月与上月金额、差额                   | 后端 compare；空期和零基期正确；不同观察时间可追溯             |
| 价格比较      | 各渠道商同料同规格最近单价             | latest 按身份/规格/币种/单位；同日多价不擅选                   |
| 缺失/异常     | 哪些没填价格/差价很大的记录            | missing 后端筛选；差价阈值不明确时追问                         |
| 解释/核对     | 总金额怎么算，为什么纳入               | 后端汇总，sources 绑定真实范围和依据                           |
| 业务建议      | 结合本月采购和库存给补货参考           | advice 与事实分开，不能编造阈值、销量或售罄预测                |
| 数据不足      | 哪些畅销/哪些快没货                    | 无销量不判断畅销；无阈值追问                                   |
| 不完整/失败   | 待确认、未查完、查询失败、取消         | 不冒充零结果或全量，必要警示保留                               |
| 隐私/账号     | 价格输入、旧答案、切换隐私、跨账号     | 模型输入与 HTTP/界面同时保护，复用 owner/CAS，晚到结果不覆盖   |
| 恢复          | 超时/预算后继续、来源变化              | 事实重读、引用重建、累计成本不清零                             |

验证分层：单元测试核验确定性计算和执行边界；真实模型核验工具选择；隔离开发库独立 reader 核验当前事实；真实认证 HTTP/桌面/手机检查交互。成功一次不代表所有问法稳定。失败报告保留，核心场景至少三次，生产、并发负载和密码登录不包含在本轮验收内。
