# P7—P10 整体架构重构交接

2026-11-18，开发工作区。AI 助手影响：已同步。

## 已实现

HTTP 会话服务改用 `assistant-agent-v1`：理解 → 可组合只读工具 → 服务端事实集合/Decimal 整理 → 模型组织 `answer-v1` → 引用与表达校验 → 每轮答案展示。原固定三步循环只保留历史协议回归，不再是新会话入口。

- 工具、字段和能力目录：`composable-contracts.ts`；实际数据来源复用既有候选、字典、语义匹配、采购及库存 reader。没有自由 SQL、脚本执行或业务写入。
- 事实集合与计算：`fact-sets.ts`、`fact-operations.ts`，覆盖筛选/排除、身份去重、分组、排序、分区 Top N、最近记录、期间/同规格单价比较、缺失检查、一对一合并和来源核对。金额/数量计算使用既有 Decimal。
- 执行与恢复：`composable-agent.ts`，统一强制单函数 `next_action`；默认每命令 12 调用、200000 预留 tokens、120 秒。显式继续可使用新命令预算，累计调用/成本不清零；相关性判断仍有独立累计预算。恢复重读事实并重放 journal，不复用旧库存冒充实时值。
- 回答：`answer-document.ts`，名称、链接、数值、日期由事实引用填充；字段错误允许预算内修正一次，仍失败使用主查询事实和用户字段兜底，页面明确显示组织失败提示。排序分区跨工具调用保留；含未知的已知金额/库存标注“已知部分”。
- 会话：查询范围、表达要求、可重放整理和澄清分开保存。月份纠正保留表达；reset 清除旧任务；每轮答案各自保存观察时间。旧结果可读，旧未完成执行进入新架构重新查询并保留成本。
- 隐私：输入前移除受保护事实及历史，禁止私密字段计算/字典和读取名称的语义匹配；HTTP 隐藏受保护历史文本及回答。切换立即隐藏、终止在途客户端请求，并通过 revision 取消服务端旧执行，未抢占的旧请求同样失效；已发出的上游请求不能撤回。
- 展示：`assistantAnswer.tsx` 和现有会话页，以每轮回答为主体；名称链接、列表、表格、文字和参考建议按要求展示，查询/来源/执行详情折叠，长列表每页 100 条。

“仅名称”按真实目录身份去重，不合并同名不同货品；单条匹配物料采购链接批次，多批次链接目录，不附金额、库存、图片、固定表格或汇总。影响结论的待确认/完整性警示仍保留。

架构与数据边界见 [架构](../composable-architecture.md)、[能力目录](../capabilities.md)、[场景矩阵](../agent-acceptance.md)。原计划 P1—P6 历史完成记录保留，P7—P10 已补充。

## 仍受限制

- 每个来源集合最多 5000 行，每执行最多 12 个集合/累计 20000 行。预览有界，答案展开完整已查询集合；超过能力或预算显式暂停/说明，不把第一页当全量。
- 观察时间按各次查询保留，不宣称跨查询事务快照；恢复重新读取。引用校验能约束事实来源和数值，不能证明模型的所有文字推理或阈值理解正确。
- 无销量/订单/消耗依据，不能判断畅销、预测用完时间；无系统低库存/异常差价阈值先问。未知采购人不能用录入者代替。商品没有物料采购来源余量能力。同日多个价格、规格缺失或单位/币种不一致不能强行比较。
- 隐私开启时需要读取名称的语义查找明确待确认，不能绕过策略调用相关性模型。隐私是现有展示/模型输入偏好，不新增角色授权机制。
- 只在隔离开发库验证，业务只读，助手测试会话已精确清理；无新增迁移/业务表、无生产访问/部署、无提交/推送。未运行全仓 E2E、生产构建、密码登录、真实提供商故障注入或并发负载测试。
- 银价页面、货损定价、Prisma 业务迁移及其他并行工作保留，不纳入本轮助手能力或交付。

P7—P10 任务占用已释放。后续按实际反馈补充语义案例，不自动开启语音、向量库、业务写入或生产部署。
