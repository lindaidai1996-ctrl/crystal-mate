# 文字助手使用与运行说明

2026-11-17。适用于 P6 文字版；实际验收证据与失败记录见 [P6 交接](handoffs/2026-11-17-p6-01-04.md)，状态见[执行计划](../ai-assistant.md)。语音输入、语音播报、自动学习及规则管理界面尚未实现。

## 使用

登录后从管理导航进入“AI 助手”，中文路径 `/zh/admin/assistant`，英文路径 `/en/admin/assistant`。新建会话后输入问题；刷新或切换会话可恢复本人已保存的消息、条件和执行状态。

可查询商品、物料、渠道商地点、采购与库存，例如：

- “帮我找下这个月我去荔湾广场买了哪些绿松石相关的配件。”制作物料语境包含圆珠，不要求存在同名“配件”标签。
- 接着问“只看圆珠”“只看提溜”“按供应商汇总”“改为上个月”。未变更的材质、用途、日期、地点应保留；可展开生效条件核对。相对月份使用北京时间与后端参考时钟，固定验收时钟不等于应用永远查十一月。
- “这些还剩多少”查看筛选所得物料/商品的**全部当前库存**；“这次买的还剩多少”查看**原筛选所选物料采购行的当前来源余量**。已有查询内这两个明确追问由后端固定映射口径，并保留筛选。前者不会把历史采购日期当库存批次日期限制；后者不代表目录总库存。若上一条仅查询目录，没有采购来源范围，或对象为商品，来源余量需要澄清，不能拿总库存代替。
- “查找荔湾广场的渠道商”：确定地点匹配与地点待确认分开列出。仅“荔湾”区域不能证明在“荔湾广场”；显示匹配片段及依据，点击渠道商打开真实详情。新查渠道商需清除上一条采购/物料筛选；不支持把物料语义用于直接地点渠道商列表。

业务事实由只读后端读取，模型不能编写 SQL 或计算金额/数量/库存。结果保留真实采购身份，近似名称不合并；明细可分页，完整汇总不随当前页变化。不同币种、串/颗/克/件分开；未知值和未知行数另列，不补成零、不任意换算。采购币种当前按明确标记的 CNY 业务默认，不能由商品售价币种推断。

点击明细可打开商品/物料原记录；物料采购/来源余量链接到对应采购批次行。历史记录缺图片或规格显示未知。当前 DIY 用料并不自动扣库存，助手沿用业务口径。观察时间表示读取时间，不承诺显示后的库存始终不变；新问题/重试会重新读取事实。

## 查看状态和处理问题

展开条件、证据、完整性和执行记录，核对候选、已读、已判断、待确认、未评估及版本。完整判断中存在待确认项时，明细/金额/数量/库存只包含确定 include 集合，并显示警示；不能把确定集合称为所有可能匹配。直接渠道商查询同样将地点待确认项单列。

- **预算暂停**：点击“继续查询”。默认每步最多判断两批、每批十条；44 候选主例实测需要两次显式继续。需要时可在“继续 / 重试的累计预算”里提高允许的累计上限；已经消耗的调用与预留不清零。暂停不是查无记录。
- **待确认**：用新消息明确地点、材质、来源范围或无法识别的业务口径。当前没有真实采购人字段，不能把录入者当采购人。
- **失败/超时/未完成**：查看安全错误及完整性，按需显式继续/重试或缩小范围；不自动付费重试，不生成零值成功结果。
- **取消**：阻止旧执行写回；已经发出的上游请求可能已收费。切换会话、隐私改变后旧响应不能覆盖当前界面。
- **中断恢复**：服务进程中断/租约过期会显示未完成，显式继续/重试重读来源。来源、查询、规则/提示词或相关性模型配置变化后不能复用旧语义判断；金额、数量、库存始终重新读取。

“应包含”“不属于”“理解错了”仅保存本人执行的 pending_review 反馈。前两类绑定真实目录/采购行，理解错误需说明；不自动学习、不改规则或业务数据。

HTTP 默认脱敏；界面脱敏开关开启时立即隐藏价格及可能含成本的自由文本，包括名称、问题、条件、证据、地点片段和反馈备注。数量、库存、日期、数值规格仍保留。图片未做 OCR 脱敏；此偏好沿用现有权限，不替代账号授权。会话和反馈按本人隔离，现有共享业务范围不等于每人拥有独立业务库。

## 开发环境运行

依照 [开发隔离流程](../../../deploy/DEVELOPMENT.md) 配置 `.env` 与已有开发 SSH 通道。`DATABASE_URL`/`DIRECT_URL` 必须指向 `127.0.0.1:15432/crystal_mate_dev`、用户 `crystal_dev`，不得改为生产目标。`npm run dev` 已通过 `scripts/with-dev-db.mjs` 启动，不要绕过隔离流程，也不要重启其他会话服务。

```bash
npm run dev
# 打开 http://localhost:3000/zh/admin/assistant
```

服务端配置为 `ASSISTANT_API_KEY / ASSISTANT_BASE_URL / ASSISTANT_MODEL`。相关性可独立设置 `ASSISTANT_RELEVANCE_API_KEY / BASE_URL / MODEL`（完整变量均以 `ASSISTANT_RELEVANCE_` 为前缀）；未设置时继承助手配置。密钥和地址可再回退 `DEEPSEEK_API_KEY / DEEPSEEK_BASE_URL`；地址最终默认 `https://api.deepseek.com`，模型最终默认 `deepseek-flash`。不读取图片模型变量。只在服务端配置，不打印配置对象/密钥；换提供商需匹配密钥、地址、模型并重新验证协议及核心案例，详见[兼容性](model-compatibility.md)。

已存在的开发库助手表可直接使用。P6 本轮未执行迁移，只写并精确清理助手验证记录。新环境如缺表，应只审核、应用助手会话和反馈指定迁移及登记；不要使用全量 `migrate deploy/dev` 顺带执行其他会话待迁移。业务表只读、冻结基线不得覆盖。生产迁移和发布不在本轮授权内。

## 验证与用量

```bash
# 离线/内存适配器，无真实模型、无数据库
npx vitest run tests/unit/ai-assistant-*.test.ts
npx tsx scripts/check-ai-assistant-acceptance.ts
# 显式 --real 才会产生真实模型请求，使用冻结适配器，不连库
npx tsx scripts/check-ai-assistant-acceptance.ts --real
# 当前开发库：业务只读，--real 额外调用模型并写/清理助手专用记录
node scripts/with-dev-db.mjs tsx scripts/check-ai-assistant-delivery.ts
node scripts/with-dev-db.mjs tsx scripts/check-ai-assistant-delivery.ts --real
# 有明确真实流程验证需要时，使用已有开发服务；不是全仓 E2E 套件
node scripts/with-dev-db.mjs tsx scripts/check-ai-assistant-delivery-browser.ts --real
node scripts/with-dev-db.mjs tsx scripts/check-ai-assistant-delivery-browser.ts --real --text-views-only
npm run typecheck
npm run lint
npm run format:check
git diff --check
```

`--only=REAL-05,FACT-05` 可用于定向诊断，报告明确 `completeMatrix=false`，不能代替完整矩阵。报告每次新建，不覆盖失败。浏览器 `--resume-main=...` 是显式复用旧已验证执行的合成助手记录，报告标记 seededMain，不能算再次真实主例调用。

耗时、实际调用和 provider 返回 tokens 见[性能记录](verification/2026-11-17-p6-performance.json)；预留 token 是保守预算，不是账单。没有取得有效价格依据，货币费用不估算。实测只覆盖当前小规模与顺序样本，部分脚本同时运行，不是受控负载基准；没有 p95、并发吞吐或 5000 行真实模型性能保证。

## 已知边界

单次硬范围最多 5000 候选，库存涉及的批次也最多 5000；地点扫描最多 5000 家。超限显式未完成/失败，需缩小范围；不是无限量数据库分块或后台任务。直接地点列表有界返回，不声称大规模渲染/并发验证。

独立 P2/P3 工具内存运行有 10 分钟有效期；应用 P4 使用持久检查点、150 秒租约、账号/revision/CAS，可跨服务调用重建。没有做多实例负载或队列验证。保留语义索引暂缓决定：当前有限案例召回通过，不代表已测向量性能；没有跨查询事实缓存。

自然语言仍受模型与现有证据限制，真实回归曾出现非法证据/身份、月份和库存口径错误；修复与失败记录均保留，不能保证所有自由问法。测试 JWT 经真实认证回调，未测密码登录；未测真实提供商 429/5xx/超时、全量 E2E、完整 build、生产或语音。故障恢复与晚到响应主要为服务 mock/HTTP mock 证据。

**AI 助手影响：已同步。** 本说明对应文字契约、编排/地点与两种库存展示、待确认事实、隐私与缓存边界；业务字段和冻结基线不变。最终验收层次和未测范围以 P6 交接为准。
