# P5 助手界面与 HTTP 契约

2026-11-17。独立入口 `/[locale]/admin/assistant`，接入现有导航、主题、Ant Design、中英文及“脱敏模式”。桌面会话侧栏，手机纵向布局与结果卡片。没有语音、规则管理或自动学习入口。

## 认证与传输

路由只调用 `conversation-service.ts` 的认证 facade；账号由 `requireAccount` 提供。低层 store/facts、owner、检查点、来源指纹、模型载荷不向浏览器开放。

| 路由                                | 方法与用途                                                                                                         |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `/api/assistant/conversations`      | GET：本人会话稳定分页，每页 30；POST：创建会话                                                                     |
| `/api/assistant/conversations/[id]` | GET：白名单会话快照；POST：message/continue/retry/cancel，必须携带 revision；PATCH：修改名称；DELETE：删除本人会话 |
| `/api/assistant/feedback`           | POST：三类待整理反馈                                                                                               |

请求采用严格 Zod、20KB JSON 上限、同源校验和审计封装，返回 no-store 与安全错误码。未登录 401、非本人会话 404、过期 revision 409、跨源写入 403。消息与反馈各显示最近 50 条并明确提示边界；会话列表可继续加载。

沿用 P4 原生 fetch、强制单个非流式工具协议，无新 SDK/依赖。浏览器约每 1.2 秒读取现有持久执行阶段，不生成虚构 token 流或进度。切换会话更新 URL `?conversation=id`，刷新可恢复；连续追问、取消、继续、重试复用 P4 服务。

客户端 epoch、读取序号、会话 ID、revision 与服务端租约/CAS 联合保护。切换/取消 abort 旧请求；POST 响应不直接安装，完成后按实时隐私设置重新读取。继续/重试可显式调整 schema 范围内累计预算，既有消耗不清零；上游在途费用仍不可撤销。

## 会话管理与加载状态（2026-11-17）

会话列表每项提供“重命名 / 删除”菜单。名称为 `AssistantConversation.title` 独立可空字段，去除首尾空白后限制 1～80 字，沿用自由文本最小化。未提问时按本人当前会话的创建顺序显示“新建会话1、2…”，分页延续编号，创建新会话不会改变已有编号；删除会话后按当前列表重新编号。不再展示会话 ID 或其截断值。

首次提问在保存消息的同一事务内，以问题文本生成最多 32 个 Unicode 字符的简短标题，超长追加省略号，合并换行及多余空白，并沿用敏感模式最小化；不额外请求模型。后续追问、继续或重试不覆盖标题，用户手动命名优先。既有未命名会话从第一条已保存问题派生标题，无需迁移或批量改写历史数据；客户端轮询发现新 revision 后刷新会话名称。

改名不修改查询 revision 或中断查询。名称只用于界面，不传入模型或作为查询条件。脱敏模式下服务端列表仍返回空名称，客户端立即隐藏现有名称并关闭名称编辑弹窗，改用编号默认名称；不会通过标题泄露问题中的金额等自由文本。

PATCH 接收严格 `{ title }`，DELETE 以路由 ID 为准；均验证当前账号与同源写入。删除前确认，数据库按既有外键级联清理该会话的消息、执行和反馈，不修改业务记录。删除当前会话时清理 URL、快照与在途客户端请求；服务端已删除父记录使晚到执行无法保存或完成，上游已发出的请求与费用无法撤销。列表请求序号防止旧响应恢复被删会话或旧名称。

读取会话改用主题色加载图标与对话骨架屏，提供状态文本和减少动态效果适配；读取失败时展示重试提示，不持续显示加载动画。桌面与手机保留现有布局。

迁移 `20261117040000_assistant_conversation_title` 仅增加名称字段，已单独应用到隔离开发库，生产未迁移。重新生成 Prisma 客户端后需重载本地开发服务，避免 Node 模块缓存继续使用旧字段定义。

AI 助手影响：已同步。涉及本人会话管理、名称隐私和持久化，不改变商品/物料/采购/库存查询契约或模型提示。认证与输入/隐私单元测试、开发库持久化/跨账号隔离/级联删除/删除后晚到写入验证见 `scripts/check-ai-assistant-conversation-management.ts` 与[验证记录](verification/2026-11-17-conversation-management.json)；运行该脚本默认不调用模型，`--migrate` 只执行本次指定 SQL。真实认证 HTTP 验证见[接口记录](verification/2026-11-17-conversation-management-http.json)，浏览器合成 HTTP 状态与桌面/手机界面检查见[界面记录](verification/2026-11-17-conversation-management-browser.json)。未触发真实模型请求，也未验证生产部署。

## 结构化结果与完整性

`display-data.ts` 在只读事务提供真实名称、图片键、规格，物料采购优先采购行规格/图片并按现有目录封面回退。历史结果缺字段时显示未知，不补造。`result-view.ts` 生成白名单与真实业务详情链接；商品、物料、渠道商及采购行身份保留。

明细、文字摘要、全量和渠道商汇总引用同一后端事实集合。P2 Decimal 金额/数量字符串、当前库存原样展示；客户端只分页，不重新计算汇总。每页 5/10/20 条，不改变全量总计；币种、单位、未知数和 CNY 业务默认明确区分。历史采购筛选确定对象，catalog_current 按全部当前批次口径；purchase_remaining 只显示所选物料采购行余量，明确标注不同口径、采购量和未知余量。

展示生效条件、pendingPlan、证据/判断、候选与判断覆盖率、未读/未判断/待确认、版本和累计预算。未知计数保持 null。no_results、needs_confirmation、query_failed、model_failed、incomplete、budget、timeout、cancelled 分别显示；只有完整确定查询才能下无结果结论，失败或未完成不投影空 facts/零金额。

## 脱敏边界

HTTP 缺省开启隐私，只有 `x-assistant-privacy: off` 才返回价格展示字段。开启时移除明细采购金额/单价、全量/分组金额，同时隐藏任意业务名称、问题/澄清文本、条件、证据原文/理由和反馈备注，避免自由文本嵌入成本。客户端切换时先立即隐藏，再重新读取。数量、库存、日期、数值规格与随机图片键保留；图片内容沿用现有业务页面边界，未做 OCR 脱敏。这是现有展示偏好，不是新增角色权限。

## 纠正反馈

`should_include / does_not_belong / misunderstood` 对应“应包含 / 不属于 / 理解错了”。前两类必须关联真实目录或采购行，可选已判断/结果记录，也可填真实 ID；后端只读验证存在性及目录/采购关系。“理解错了”必须说明原因，可不指定记录。

新增 `AssistantFeedback`，保存认证 owner、会话/执行/原问题消息、服务端规则/提示词版本、最小化备注和请求 UUID。重复相同请求 ID 幂等，不同载荷拒绝。状态固定 `pending_review`；单次反馈不更新规则、执行 revision/状态或业务记录。规则整理确认流程尚未实现。

迁移 `20261117020000_assistant_feedback` 仅在隔离开发库应用；不得用全量 migrate deploy 顺带执行其他会话迁移。生产迁移与发布另需授权。

## P6 文字补充

完整判断含 uncertain 时，浏览器只显示确定 include 集合的真实明细/汇总/库存，警示待确认未计入；不能把该集合称全体可能匹配。来源库存每个采购行独立展示采购量、当前余量及批次详情链接，手机卡片与桌面表格使用相同后端数值。

直接地点渠道商分确定/待确认两组，显示名称、区域、理由和匹配片段，链接真实详情；不输出完整地址、联系方式或无关备注。隐私模式同时移除名称、区域和片段，立即切换时也隐藏已有自由文本。

新增两种库存/渠道商真实模型 HTTP 与当前开发库独立 P2/地点解析对照，桌面 1440px、手机 390px 的口径、来源身份/链接、隐私和无横溢检查见 [P6 交接](handoffs/2026-11-17-p6-01-04.md)。原主例及手机圆珠追问另有真实模型浏览器记录；FLOW-06 为构造 uncertain 加真实只读事实展示，不冒充模型歧义实测。AI 助手影响：已同步。

## P7—P10 更新（2026-11-18）

每条助手消息和最新执行新增可空 `answer`，采用 `answer-v1` 的已校验白名单文档；历史回答持久化，各自保留观察时间。消息直接显示名称链接、文字、列表或表格，查询范围、时间/来源及执行详情折叠；仅名称不展示固定结果表格。旧结果仍可展开读取。

隐私关闭时必要业务数值可进入模型；开启时模型输入前剔除受保护事实/历史，自由文本答案在 HTTP 投影整体隐藏。切换隐私立即清除客户端旧快照并中止在途请求；cancel 可附加 `reason=privacy_changed`，服务端在无活跃执行时也使旧 revision 失效，阻止尚未抢占的旧请求随后执行，同时保留已完成历史答案。普通 cancel 保持原幂等行为。详见 [新架构](composable-architecture.md)及 [P7—P10 交接](handoffs/2026-11-18-p7-10.md)。
