# 助手能力目录：现有数据边界

2026-11-20 银料采购台账：真实采购金额、重量、日期、供应商及未知余量沿用既有工具读取；折前报价、折扣、批次用途与Excel导入草稿/回执不提供自然语言查询。详见[银料采购](../../silver-procurement.md)。

2026-11-18，`assistant-agent-v1`。模型实际消费 `ASSISTANT_CAPABILITIES`；本表记录数据依据。具体实测记录与局限见 P7—P10 交接，不把工具存在视为所有自然语言问法已经验证。

| 能力                           | 实际来源/操作                      | 边界                                                     |
| ------------------------------ | ---------------------------------- | -------------------------------------------------------- |
| 名称、规格、链接               | 目录及采购行展示 reader            | 身份来自数据库，链接后端生成；未知规格不推断             |
| 模糊找货、组合语义、排除       | 原有候选、真实字段证据和相关性服务 | 歧义候选需确认；不要求必须存在同名标签                   |
| 日期、地点、渠道商、分类、标签 | v1 查询、地点解析、动态字典        | 上海月份、[from,to)；区域不等于确切地点                  |
| 采购明细、数量、单价、金额     | 原采购 reader 和 Decimal           | 单价与行金额不同；缺失保留未知；CNY 为采购业务默认       |
| 当前库存、采购来源余量         | 原库存 reader                      | 目录总库存与物料采购行余量不同；商品无来源余量字段       |
| 去重、筛选、排序、分组、Top N  | 完整有界集合及 transform           | 真实身份去重，单位/币种隔离；预览不是全量                |
| 时间比较、新增货品、差额       | 两个完整查询及 compare             | 不完整不能全量比较，未知不能填零，零基期不输出变化百分比 |
| 最近采购价、渠道商比较         | latest、同货品/规格/单位/币种      | 同日不同价格和未知规格不可可靠比较                       |
| 缺失/异常检查                  | missing/present、数值筛选、比较    | 未设异常阈值时追问，不发明业务规则                       |
| 解释与核对                     | sources、原字段证据、计算来源      | 不向模型发送完整地址、联系方式或无关备注                 |
| 连续追问、纠正、表达偏好       | 会话条件、task、历史消息           | 切换日期保留其他要求，reset 清除旧任务，事实重读         |
| 补货参考建议                   | 已有采购/库存事实及 advice         | 无低库存标准先问；建议不是销量预测或采购承诺             |

尚无助手数据能力：销量、订单、真实采购人、真实消耗速度、售罄时间、系统低库存/异常差价阈值。DIY 用料目前不自动扣库存。商品名片、银价行情等其他页面的存在不代表已接入助手。

本次没有增加上述业务模块、语音、自动学习、自由 SQL、业务写入或向量数据库。新增业务字段、计算/单位/币种或权限口径后，继续按 maintenance.md 复核工具和答案，不能假设页面变更会自动传播。

物料页面的[计量单位纠错](../../material-unit-correction.md)支持在统一更正单位时补填各批次数量、库存、金额和价格，不按固定比例强行换算。助手重新查询采购／库存时读取更正后的当前单位与确认值，并按单位分组；历史答案保留原查询快照。助手不提供单位纠错写入或相关审计查询。

物料[统一计价](../../material-unified-pricing.md)复用原采购关系，采购与库存查询口径保持不变。计价组、货损率、含货损估算成本、行情、建议售价、调价历史，以及DIY用料/成本明细暂未接入助手；不能把平均采购成本当成准确库存成本，也不能把货损分摊当作真实采购金额或库存损失。
