# DIY 看图选料与最近使用

2026-11-17。选料入口位于 DIY 用料与报价，电脑使用宽面板，手机使用全屏面板。沿用当前主题、图片裁切与原图预览、价格隐私模式及计价规则。

## 使用方式

- “添加物料／添加蛋面”打开可多选面板；已有用料行保留快搜，并提供“浏览全部”进行单行更换。
- 物料按款聚合，展开确认批次；一个匹配批次时直接选择。批次图片优先，无图片时回退到物料图片。
- 物料卡片使用横向缩略图与信息区，手机每行一款；批次的渠道商、日期、规格集中显示，库存与进货价并排，选择区域独立。图片右下角仅展示图标与张数，点击整张缩略图查看原图。
- 添加物料默认优先使用颗；添加／更换批次时，如果当前单位缺少进货价，则依次寻找有价格的颗、克、串，并同时带出对应投入价与对客价。零元是有效价格；全无价格时保留当前单位供手填。按克管理的物料仍限用克。看图选料、行内快搜和图片导入的批次选择共用该规则；已保存的用量单位与手动切换单位不自动重写。
- 蛋面展示图片、名称、编号、尺寸和库存，排除当前 DIY 商品自身。
- 支持关键词、标签、库存、长宽高范围筛选；物料增加分类树及渠道商。尺寸单位为毫米，范围包含边界，缺失尺寸不匹配已指定的条件。
- 物料尺寸、库存、渠道商必须在同一个批次满足；总数按物料款数计算，每页 24 款。
- 默认展示全部库存状态，包括零库存和库存未知；“仅有库存”只匹配明确大于零的库存。
- 跨页、跨筛选保留勾选，按勾选顺序添加；取消不修改草稿。允许同一来源新增独立用料行，不合并已有数量或手填价格。
- 同一编辑会话中保留面板筛选；更换保留目标行用量并按既有逻辑更新建议价格，其他行不变。

## 接口与账号隔离

`GET /api/diy-picker/materials` 和 `GET /api/diy-picker/cabochons` 使用 `requireAccount`，返回 `no-store` 的分页结果。

参数：`q`、`source=all|recent`、`tagId`、`stock=all|available`、`lengthMin/Max`、`widthMin/Max`、`heightMin/Max`、`page`、`pageSize`（最多 24）。物料支持 `categoryId`、`distributorId`；蛋面支持 `excludeProductId`。无效范围、页码或 ID 返回输入错误。

个人最近使用保存在 `DiyRecentMaterial` 和 `DiyRecentCabochon`，每账号每种类型最多 30 项，仅存目标 ID 与使用时间，不存图片、价格快照。

- DIY 新增、修改、来源更正及新建商品直接保存 DIY 时，在业务事务内更新。账号从 `requireAdmin` 验证后建立的服务端审计上下文取得，不接受请求体账号。
- 试选、取消、失败保存不更新。删除 DIY 不清空操作历史；目标被删除时关联历史级联清理。
- 同账号的并发更新锁定账号行再去重更新、裁剪；个人历史错误会令业务事务一起回滚。
- 最近使用回源读取当前展示信息，物料仍按款聚合；账号无历史返回空结果，不能回退成全部。
- 不回填无法判定个人归属的旧 DIY 历史；无交互账号的后台调用不创建个人历史。

## AI 助手影响

**AI 助手影响：无需同步查询能力。** 本改造复用现有字段、批次、库存单位及 DIY 计价口径，个人最近使用仅用于选料界面，不接入助手契约、证据、模型输入或会话。批次布局与选料默认单位调整仅影响编辑草稿，沿用既有单位对应的价格字段，不改变单位枚举、换算、库存或后端计算；助手继续读取保存后的实际用料单位与金额。已复核历史按认证账号隔离、价格沿用现有隐私模式；此说明不代表助手支持查询个人最近使用。
