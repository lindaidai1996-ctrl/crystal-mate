### 形状、排版和布局：采用最终 B/D 共用结构

- 页面与控件采用直角。常规操作按钮约 44px 高，清楚区分主次操作；边框细、阴影克制。
- 以 4px 为基础间距。桌面内容左右留白约 56px；顶栏约 80px 高，侧栏约 216px 宽。1280px 以下相应缩小留白。
- 1440px 画廊三列，图片 4:5；横向间距 32px，纵向间距 44px。卡片减少包裹框，图片和文字用间距、细线组织。
- 1280px 以下画廊两列，手机一列。800px 以下导航折叠为抽屉；表格仅在自身容器横向滚动。
- 舒适表格缩略图约 76px、单元格上下内边距 24px；紧凑模式约 64px 和 12px。高密度业务表格可据内容选择紧凑模式。
- 表格弱化外围卡片边框和表头填色；保留必要固定列、排序、分页和所有业务字段。
- 编辑页减少卡片嵌套，用分组、留白与细线组织字段；输入控件采用底边样式，但保留清楚的聚焦、错误、只读和禁用状态。
- 中文沿用 B 的清晰无衬线字体，不继承 D 的宋体商品标题。基础字号 14px，按数据密度设置辅助字号。
- 微交互约 160ms，支持 `prefers-reduced-motion`。移动端主要操作保持可点击尺寸，键盘可见聚焦。

### 技术实现

- 用 Ant Design `ConfigProvider` 的全局 Token 与组件 Token 统一样式，保留已有 CSS 变量和多语言接入。
- 建议将正式主题集中到 `src/lib/ui-theme.ts`，通过 `src/components/app-providers.tsx` 接入；导航、标题工具栏、商品卡片和表单布局使用作用域明确的 CSS Modules。
- 按需抽取页面工具栏、商品卡片和视图切换等业务组件；不要机械包装全部 Ant Design 组件。
- 避免大量全局 `.ant-*` 覆盖与 `!important`；浮层、抽屉、日期选择器、上传和表单错误态也应检查主题效果。
- 不复制原型 CSS 到全局后再逐项打补丁；将原型 Token 和结构映射到现有 React/Ant Design 组件。
- 这一轮通常无需改变 API、数据库 schema、权限、路由或引入新的依赖。
