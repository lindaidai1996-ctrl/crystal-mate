# 公开金银价查询页

入口：`/yj`，英文为 `/yj?lang=en`，默认查看银价；`/yj?metal=gold` 直接查看金价，支持组合 `lang=en`。页面标题旁的“银价 / 金价”按钮切换最新行情和历史图，复用同一布局与日期筛选。切换同步更新地址，语言切换保留当前金属。旧入口 `/silver`、`/silver?lang=en`、`/zh/silver-price`、`/en/silver-price` 跳转至对应的新入口。

页面和只读接口均无需登录，不读取业务数据库。金银行情相关组件与服务统一放在 `src/components/metal-market/`、`src/lib/metal-market*.ts`。

## 行情口径

- 白银为上海黄金交易所 Ag(T+D)，黄金为 Au(T+D)，均由东方财富公开行情接口提供。大盘参考行情不等同于后台银料成本、报价或首饰成品售价。
- 报价先按精度字段 `f59` 还原。白银原始单位为元/千克，再除以 1000；黄金原始单位已是元/克，不再除以 1000。历史每日收盘价采用对应的同一单位换算。页面统一显示元/克，并辅助显示元/千克。
- 报价时间使用源数据 `f86` 秒级 Unix 时间戳，以北京时间展示；涨跌额和幅度相对于源数据昨日收盘价计算。金银响应必须与请求标的相符，否则按数据异常处理。
- 页面可见时每 30 秒查询报价，切回页面也查询。手动刷新显示加载、完成或未变提示；失败时保留已有报价并标注，首次失败展示重试。切换金属时清空旧视图并中止旧请求，避免显示另一标的的报价或图表。
- 历史图展示交易日每日收盘价，当日点位仍可变化；不补休市点、不补零。支持近 1 月、3 月、半年、1 年、3 年、全部及自定义区间。两个标的当前可用起点均为 2012-06-05。包含今天的历史区间每 5 分钟查询。
- 日期复用 `DateRangeFilter`，桌面为范围选择器、手机为底部抽屉日历。清空查看全部历史，非法日期不发请求；快速切换历史范围有 300 毫秒防抖，重复点击同一预设不重发查询。
- 图表支持鼠标、触屏及键盘查看每日价格，并处理单点、空区间、加载与错误状态；黄金坐标轴为较长价格标签预留空间。中英文和手机布局复用原银价页设计。

## 刷新与接口保护

- 每次手动刷新或错误重试后进入 10 秒冷却，按钮禁用并显示倒计时。冷却在金银切换之间共享，请求尚未结束时按钮也保持禁用。
- 服务端同一 IP 在一个 60 秒窗口内最多 30 次请求，两个金属、报价、历史、非法查询及旧 API 共用额度。超限返回 `429`、`Retry-After` 秒数及 `Cache-Control: no-store`。页面根据响应进入等待倒计时，自动查询对该请求遵守退避时间。
- 单进程应用缓存按金属/查询范围隔离：报价 30 秒、历史 300 秒，同一查询的并发请求合并；上游失败缓存 5 秒，避免故障期间重复请求。缓存最多 200 项、限流最多 2000 个客户端窗口，窗口结束后清理；达到客户端容量时保守拒绝新窗口。Next fetch 重验证仍为报价 30 秒、历史 300 秒。HTTP 响应不缓存，确保请求经过服务端限流。
- IP 来自入口 Caddy 强制覆盖的 `X-Real-IP`，内部只存哈希；缺失或非法 IP 共用 fallback 桶。部署时必须同时重载更新后的 `deploy/Caddyfile`，应用端口继续仅监听服务器回环地址。当前方案适用仓库单机单进程部署；重启会重置缓存和窗口，多实例需改共享存储，入口增加 CDN 需重新设置可信 IP 来源。参见 [部署说明](../../deploy/README.md)。

## 接口与运行

- 最新报价：`GET /api/public/metal-price?metal=silver&view=quote`；`metal=gold` 查看金价。省略 `metal` 默认白银，省略 `view` 默认报价。
- 历史：`GET /api/public/metal-price?metal=gold&view=history&from=2025-12-01&to=2026-01-31`。
- 旧 `GET /api/public/silver-price` 保留为白银兼容入口，强制白银并共用同一限流和缓存。
- 仅接受 `silver/gold` 与 `quote/history`，历史日期必须真实且在可用起点与北京时间今天之间。非法参数返回 400，源异常或不完整数据返回安全的 502，不泄露原始错误。
- 只访问固定东方财富 HTTPS 源，客户端不能指定任意 URL 或标的。请求超时 8 秒。无需新增密钥、依赖或迁移；部署网络需能访问 `push2.eastmoney.com` 和 `push2his.eastmoney.com`。

## AI 助手影响

AI 助手影响：无需同步。只扩展独立的公开外部行情展示和接口保护，不改变业务字段、成本口径、助手查询契约或业务数据权限。后台银价设置接口仍要求登录，助手没有因此获得外部金银行情查询能力。
