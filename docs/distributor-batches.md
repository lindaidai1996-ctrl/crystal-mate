# 渠道商关联批次与合作概览

渠道商详情提供“进货商品与物料 / 关联批次 / 附件”三个视图。关联批次可按名称、进货日期筛选，展开查看当前渠道商的分页进货明细；列表展示关联批次数与最近进货日期，并支持排序、直达批次视图。桌面和手机复用现有主题及组件，中英文文案同步提供。

## 统计口径

- 关联来自 `ProductPurchaseEntry` 和 `MaterialBatchEntry`，不新增批次归属字段或迁移。合并两类记录后按批次 ID 去重；供货款数按类型和货品 ID 去重。共享批次只计算当前渠道商对应的明细。
- 详情顶部、页签数量和渠道商列表展示全部历史统计，不随详情下方搜索变化。最近进货取关联批次的最大 `receivedAt`，不是记录创建时间，也不将批次数称为采购次数。
- 成品采购金额为数量乘采购成本；物料优先使用批次采购总额，否则为进货数量乘采购单价。服务端使用 PostgreSQL numeric / Prisma Decimal，返回两位小数字符串；界面沿用已有金额格式和隐私模式。
- 全部金额未知时返回 `null`；部分未知时返回已知小计及 `hasUnknownAmount: true`。真实零金额保留，不视为缺失。数量按每条明细自身单位显示，不合计不同单位。
- 进货日期是日期字段，筛选包含首尾日期。批次默认按日期、批次 ID 倒序；明细按类型、明细 ID 稳定排序，均在服务端分页，默认 20 条、上限 50 条。

## 读取接口与导航

- `GET /api/distributors`：各项新增 `batchCount` 和 `latestReceivedAt`，款数和批次统计批量读取。
- `GET /api/distributors/:id`：新增 `stats: { itemCounts, batchCount, latestReceivedAt }`。无记录时计数为零、日期为 `null`。
- `GET /api/distributors/:id/batches`：接受 `q`、`receivedFrom`、`receivedTo`、`page`、`pageSize`，返回 `{ items, total, page, pageSize }`。批次项包含封面、附件、日期、当前渠道商款数及金额完整性。
- `GET /api/distributors/:id/batches/:batchId/entries`：接受 `page`、`pageSize`，返回当前渠道商在该批次中的成品和物料明细，包含货品标识、名称、单位、数量、采购单价及金额。
- 新接口沿用管理员鉴权。非法 ID、日期、倒置范围或分页返回 400；渠道商不存在或批次无关联明细返回 404。越界分页保留真实总数，返回空列表。
- `view=batches` 明确指定详情视图，优先于会话保存值。两个进货视图的搜索、日期和分页独立保存，筛选变化清除展开状态并回到第一页。
- 批次详情通过 `distributorId` 保存明细筛选，支持清除，并保留原有 `returnTo` 校验。该筛选只影响展示，不改变授权范围；批次附件仍为整个批次的附件。批次表格分页按批次、渠道商和货品类型隔离。

## AI 助手影响

**AI 助手影响：无需同步现有能力。** 本次复用现有进货关系、金额和权限口径，只扩展管理页面及其专用读取接口。新统计不自动进入助手契约、模型证据或结果；不宣称助手已支持自然语言查询关联批次数和按批次汇总。以后接入时需新增或扩展受控查询及去重验证。

## 验证与边界

定向验证包含接口鉴权和参数校验、跨类型批次去重、重复成品进货、共享批次隔离、同名货品、款数统计、未知及零金额、日期边界、稳定排序、越界分页和手机端缺失日期排序。数据库用例只在显式配置的独立 `_test` 数据库运行。
