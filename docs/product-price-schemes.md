# 商品多价格方案

## 金额与公式

原 `Product.priceCents` 是直售价，历史金额不修改。后台“价格方案”提供命名公式、常用开关、显示顺序和取整方式。公式只能包含四个变量、十进制数字、百分比、加减乘除与括号；不执行代码，不引用其他方案。

| 变量                                   | 含义                                                                                                                       |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `cost` / 单件成本合计                  | DIY 已保存物料、银饰／统一计价用料、蛋面和其他费用的单件成本；蛋面采用已有成本合计；采购成品采用当前定价选择的最新采购单价 |
| `costWithLabor` / 单件成本合计＋手工费 | 仅 DIY：单件成本加按整批数量分摊的手工费，遵循一次性／按件累计及手动整批金额                                               |
| `quote` / 单件对客报价                 | 仅 DIY：现有单件对客报价，已经包含手工费                                                                                   |
| `direct` / 直售价                      | 商品保存或编辑中的直售价                                                                                                   |

有多条来源时按创建时间及 ID 降序选择，沿用原定价口径；修改较旧制作记录不会将该记录替换为当前方案的成本来源。物料目录行情、售价或采购变动不改写商品制作快照。

公式采用整数分子／分母表达十进制输入和中间结果，手工费分摊不提前取整。最终按方案四舍五入到分、向上取到元或向上取到十元。限额与直售价一致，为 21,474,836.47 元；未知值、不适用变量、除零、负数及超限均返回明确状态，不用零替代。公式最多 1000 字符、128 个语法项，限制数值及中间运算规模。

## 保存与重算

- `PriceScheme` 保存当前方案；`PriceSchemeRevision` 保留每次编辑的规则版本；`ProductSchemePrice` 保存商品价格、计算依据、计算版本及状态。
- 自动价格只在依赖的金额或计算结果变化时更新。与公式无关的商品名称、备注等修改不会增加价格记录版本。
- 用户修改金额即标记“手动修改”，即使金额恰好等于计算值。规则更新时勾选保留的商品标记“保留价格”。两者直到用户恢复自动计算前都不会自动覆盖。
- 常用方案确认后补到全部历史商品；新建及导入的商品自动关联。取消常用不删除既有关联。普通方案可在商品上添加或移除；不能在商品上移除仍为常用的方案。
- 公式或取整方式变化先展示全部受影响商品，支持搜索、分页和跨页保留选择。手动／保留价受到保护；没有有效原价或新关联的商品不能勾选保留。
- 缺少变量或不适用的商品仍关联方案，但当前金额为 null；上次有效金额仅用于追溯，不能作为当前报价。非自动状态保存的有效金额保持原值。
- 名称、顺序和取消常用不触发批量改价。方案编辑不提供硬删除操作。
- 商品完整保存、直售价快捷修改、来源新增／编辑／删除／纠正和导入调用共同的重算服务，商品与价格在同一事务内保存。旧请求未带方案字段时保留原有配置。

## 接口与并发

管理接口均要求现有管理员会话，写入沿用来源校验和审计；新增表有数据库审计触发器。

- `GET /api/price-schemes`：方案列表及使用数量。
- `POST /api/price-schemes/evaluate`：按指定商品和公式只读试算。
- `POST /api/price-schemes/preview`：计算创建／编辑的完整影响及预览指纹。
- `POST /api/price-schemes/commit`：验证方案版本、完整影响指纹及保留集合后，在 Serializable 事务内保存规则和价格。
- 商品响应增加 `schemePrices`、`schemePricesToken`；商品保存及 DIY 价格保存可带 `schemePrices: { expectedToken, items }`。

商品编辑校验原价格状态和方案版本；批量预览后若金额、关联、状态、方案或受影响商品集合改变，返回 `SCHEME_PRICE_CHANGED`，必须刷新后重新检查。事务中任何失败均回滚，不提交一部分方案价格。价格历史不能被客户端自动结果覆盖，服务端重新读取变量并计算。

## 展示与隐私

全部商品、成品、蛋面复用同一价格展示。直售价为主要金额，最多展示两项常用方案，其余通过“更多价格”查看。方案状态、错误和上次有效金额有独立说明；列表排序仍按直售价。

隐私模式保留价格，隐藏公式和内部成本依据，包括方案管理、商品公式提示及审计中的公式／依据字段。公开展示和已有商品名片不自动增加多价格。AI 助手影响：已同步能力边界；助手尚不查询或修改方案价格。
