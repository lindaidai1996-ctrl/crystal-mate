# 移动端表格

767px 及以下，业务列表使用卡片展示，桌面继续使用表格。

## 布局与交互

- 渠道商进货列表：图片、名称、类型、数量、金额、批次数和最近进货日期直接可见，其他价格及重量信息收在“更多信息”中。
- 渠道商关联批次：展示封面、批次名称、日期、本渠道商供货数量与采购金额；可进入批次或展开明细。
- 采购明细和采购批次对比：展开内容在当前卡片下显示，嵌套表格也使用卡片。
- 其他使用 `PaginatedTable` 的分类、标签、镶嵌款式、渠道商、采购批次、来源记录等列表，按现有列生成带字段名称的卡片。
- 商品、物料、操作记录继续使用各自的定制卡片内容。物料列表的批量复选框改由表格统一提供。
- 常用操作、展开按钮、复选框及翻页按钮提供至少 44px 点击区域。

## 组件约定

`PaginatedTable` 在移动端保留 Ant Design 的数据处理流程，只调整展示列。客户端分页、排序、筛选、树形展开和行选择继续交给原表格处理；接口分页仍使用调用方传入的 `current`、`pageSize` 和 `total`。

`mobileRender(record, index)` 可定制卡片内容，也遵循上述处理流程，不再直接遍历整份数据源。`MobileTableFields` 可复用现有列的格式化、未知值说明和隐私包装，避免移动端重复实现金额或单位口径。

分组表头、虚拟表格、自定义表格组件和汇总行保留专用表格布局；调用方可显式使用 `mobileLayout="scroll"` 保留横向表格。AI 助手结果原有独立移动卡片、Excel 导入预览和图片识别差异表不经由本组件适配。
