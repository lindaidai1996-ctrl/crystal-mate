# 物料／商品采购批次对比

第一版提供同一目录对象的采购价格、数量、金额、采购间隔和批次明细对比。至少两个不同采购批次时，物料／商品列表、卡片和编辑详情显示「批次对比 · N 批」。耗尽批次仍计数，DIY 制作记录不计入。

## 页面与接口

- 页面：`/admin/materials/[id]/batch-comparison`、`/admin/products/[id]/batch-comparison`，均支持现有语言前缀及经过校验的 `returnTo`。
- 只读接口：`GET /api/materials/[id]/batch-comparison`、`GET /api/products/[id]/batch-comparison`。均先执行现有管理员鉴权；不存在的对象返回 404，非法筛选返回 400。
- 可选参数：`receivedFrom`、`receivedTo`（YYYY-MM-DD，含起止日）及 `distributorId`。日期、渠道商条件同时作用于汇总、趋势和明细；历史批次数和渠道商选项保留全部历史范围。
- 不修改数据库结构，不改变业务记录、采购计算或库存扣减规则，也不新增缓存。金额和数量使用十进制字符串，服务端使用独立的 50 位 Decimal 计算；图表坐标才转为浮点数。

## 经营口径

- 采购金额：物料优先记录的批次总金额，否则按已知采购数量乘对应采购单价；按克物料使用克价。商品按采购数量乘采购单价。币种为现有采购业务默认 CNY，不从商品销售币种推断。
- 价格趋势：优先使用采购金额除以对应采购计量数量。物料支持串／颗／克，商品按件；无法换算时保留已有手动／估算单价及其来源。按颗和按克使用对应颗数与总重量，不混用分母。
- 加权均价：仅采用金额、对应数量均完整且数量大于零的采购行；总金额除以总量，同时给出参与计算的不同批次数。某批只有部分采购行完整时，只将完整行纳入均价，不把不完整批次趋势伪装成完整数值。
- 批次按采购日期升序排列，同日按批次 ID 稳定排序；图表横轴按批次排列，不是等比例日历轴。同一商品同批多次采购合并数量、金额并加权计算单价，展开保留各渠道商采购行。同日不同批次不合并。
- 最近两批涨跌仅比较筛选后最后两个批次，不跳过缺失批次；前批价格为零时不计算百分比。平均采购间隔为首末采购日期差除以批次数减一，同日采购可为零天。
- 缺失值不补零。汇总显示已知合计和缺失记录数，明细／图表的缺失值显示为未知；价格折线在缺失点断开。
- 物料展示当前批次余量、剩余比例、库存成本估值和仍有余量的最早采购批次。估值按当前余量乘记录的采购单位成本计算，无法计算的行不纳入合计并计入缺失数。距采购天数按北京时间日期计算。
- 日期筛选不会还原历史库存。采购量减余量不是销量；商品只展示整款当前库存，不分摊各批余量。不提供真实销售、实际利润、周转预测、品质排名或自动补货建议。
- 物料规格和批次备注沿用已有字段；商品保留采购行备注。规格、颗数、重量和品相差异需经营者结合原记录判断，不能由单价直接判定品质。

## 权限、隐私与助手

沿用现有登录鉴权及浏览器隐私模式。隐私模式从 DOM 中移除采购成本、金额、涨跌、库存估值及其图表、提示和无障碍文本；即使先选择金额趋势再打开隐私模式，也只显示数量趋势。隐私模式是现有展示偏好，不是新增的服务端字段权限；认证用户仍可通过现有机制读取业务成本。

**AI 助手影响：无需同步现有查询能力。** 本轮新增独立页面及派生汇总，不改变采购／库存的业务字段或现有助手查询口径，不将对比结果加入模型输入。自然语言批次对比尚未接入；以后支持时需单独增加工具契约、单位／价格来源说明、权限、精确计算及验收案例。

## 验证及边界

- 单元测试覆盖批次去重、同批多行、同日多批、日期／渠道商筛选、重量／颗数换算、加权均价、金额精度、缺失值、零价格、库存估值、北京时间日期、接口鉴权及隐私展示。
- 已在开发库对真实物料（两个批次）及商品（一个批次）完成只读 HTTP 和桌面／手机浏览器检查，覆盖图表键盘操作、金额切换、渠道商筛选、实时隐私切换、中英文页面和详情入口。商品多批合并及入口计数通过构造数据测试，不因开发库只有一个商品批次而声称实测了商品多批经营数据。
- 浏览器使用短期签名开发会话，未验证密码登录、真实手机或生产环境；未写业务记录、调用真实模型、运行仓库 E2E 或部署。
- 本轮相关类型、lint、定向测试和全仓 `npm run format:check` 均通过；本功能修改文件也已单独执行 Prettier 检查。
