## 2026-11-10 首轮实施（历史记录）

日期：2026-11-10（Asia/Shanghai）。本轮完成计划的阶段 0、1、2，阶段 3 留作后续推广。

## 已实现

- 在 `src/lib/ui-theme.ts` 集中定义铂金主题，通过现有 Ant Design ConfigProvider 接入。采用冷白与蓝灰、直角控件、44px 常规按钮、轻阴影与 160ms 过渡；保留业务标签的原有颜色。
- 深色导航使用项目内的透明白字 Logo，保留全部导航、语言切换、退出与现有离开保护入口。桌面侧栏 216px、顶栏 80px；800px 以下使用抽屉，支持 Escape 关闭和焦点返回。
- 成品管理默认表格，可切换画廊与舒适／紧凑密度。两种视图共用真实查询结果、搜索、来源、分类计数、标签、上架、库存、日期、价格排序和分页。
- 通过现有 `useSessionListState` 保存 `${listStateKey}:view`、`${listStateKey}:density`，保持编辑与草稿返回时的页码、每页数量、筛选和排序状态。
- 画廊为桌面三列、1280px 以下两列、手机一列，图片比例 4:5。展示真实名称、编号、分类、标签、来源、价格、库存和上架状态，保留编辑、删除、图片预览与价格／库存内联编辑。缺图显示统一占位，浏览多图不更换原封面。
- 成品编辑采用图片与基本信息左右布局、底边输入框和分组细线；来源、用料、成本、定价、库存、营销、真实上传、草稿和保存逻辑保留。通过成品列表恢复的通用商品草稿也使用这套视觉。
- 增加列表请求失败后的重试展示，保留空结果的零条计数。新增界面文案同时提供中英文。

## 与原型的必要差异

真实成品列表包含更多筛选和业务字段，筛选区保留多行，表格在自身容器内横向滚动。编辑页的来源、用料、成本和营销分组采用完整宽度，避免将复杂操作塞入原型的窄列。正式页面使用现有真实上传与保存功能，没有原型的演示数据、只读限制或 Tweaks。

其他页面继承公共主题和导航；全部商品、蛋面、原物料、渠道商和复杂导入等页面的专门布局仍按阶段 3 推广。
